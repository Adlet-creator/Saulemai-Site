# SAULEMAI — сайт медицинского центра

Самостоятельный статический сайт (HTML/CSS/JS, без сборщика). **Не связан** с
Python/Streamlit-инструментом «Маркетолог ИИ», который лежит в родительской папке —
соседство случайно, другой проект.

## Как запустить локально

```bash
cd saulemai-site
python3 -m http.server 8787
```

Открыть http://localhost:8787/. Открывать `index.html` напрямую двойным кликом
**нельзя** — шапка и футер подключаются через `fetch()` и требуют HTTP, а не `file://`.

## Главное: один файл для всех неподтверждённых данных

`assets/js/config.js` — **единственное место**, которое нужно менять, когда появятся новые
подтверждённые данные. HTML-страницы при этом не трогаются. Статус на 2026-10-28:

- ✅ WhatsApp/телефон (`contact.whatsappNumber`/`phoneNumber`) — подтверждены по живому
  сайту saulemaimed.kz;
- ✅ юр. реквизиты (`legalEntity`) — БИН, расчётный счёт, email;
- ⬜ фото врача (`doctor.photoPath`) — на живом сайте есть реальное фото, но **скачивание
  файла нужно подтвердить отдельно**, прежде чем класть его в `assets/img/`;
- ⬜ подтверждение категории/стажа врача (`doctor.credentialsVerified`) — **конфликт данных**:
  на сайте сейчас «37 лет, высшая категория» (по брифу), на старом сайте было «32 года» —
  нужны документы от клиента, цифру не меняем без них;
- ⬜ ID Google Analytics 4 / Google Tag Manager / Meta Pixel / TikTok Pixel (`analytics.*`) —
  код условной загрузки уже готов для всех четырёх, ждём реальные ID;
- ⬜ ссылка на карту (`address.mapUrl` / `address.mapEmbedUrl`).

## Структура

- `index.html`, `doctor/`, `prices/`, `ginekologiya/`, `uzi/`, `checkup/`, `surgitron/`,
  `udalenie-kondilom/`, `prp-ginekologiya/`,
  `programs/`, `blog/` (+ `blog/<slug>/`, 3 статьи), `contacts/`, `privacy-policy/`, `consent/` —
  страницы сайта, каждая со своим `index.html` (чистый URL без `.html`). `prices/` —
  сводный прайс-лист по категориям (Консультации/Диагностика/Check-up/Процедуры),
  собран из уже подтверждённых цифр на сайте.
- `partials/header.html`, `partials/footer.html` — общая шапка/футер,
  подключаются на каждой странице через `assets/js/include.js`.
- `assets/css/` — стили (`base.css` — сброс, переменные и типографика; `components.css` —
  компоненты, включая новые `.doctor-showcase`/`.pricing-table`/`.promo-banner`/
  `.review-card` из направления «Солнечный свет» — готовы к использованию, ждут реальных
  данных для наполнения).
- `assets/js/config.js` — конфиг неподтверждённых данных (см. выше).
- `assets/js/include.js` — подключение partial-ов, рендер кнопок WhatsApp/телефона,
  трекинг `whatsapp_click`/`phone_click`, автогенерация BreadcrumbList JSON-LD из
  видимых хлебных крошек.
- `assets/js/analytics.js` — условная загрузка GA4/GTM/Meta Pixel/TikTok Pixel (ничего не
  грузится, пока соответствующий ID не задан).
- `robots.txt`, `sitemap.xml`, `llms.txt` — техническое SEO и видимость для ИИ-поиска.

## Перед публикацией (go-live чек-лист)

1. ✅ Домен заменён — `https://saulemaimed.kz` используется во всех `<link rel="canonical">`,
   `og:url`, Schema.org JSON-LD, `robots.txt`, `sitemap.xml` и `llms.txt`.
2. ⬜ Фото врача — скачать с живого сайта (нужно отдельное подтверждение на скачивание файла)
   и подключить в `config.js` / `assets/img/`.
3. ⬜ Подтвердить документы врача (диплом, сертификат специалиста, категория, стаж) —
   до подтверждения на странице `/doctor/` сохраняется формулировка «по данным
   медицинского центра», `doctor.experienceYears` в config.js не добавлять.
4. ⬜ Подтвердить цены (флаг `flags.pricesVerified`) и условия сотрудничества с INVIVO
   (флаг `flags.invivoPartnershipConfirmed`) — логотип INVIVO не публикуется без
   подтверждённых договорных прав.
5. ⬜ Подключить Google Search Console и GA4/GTM/Meta Pixel/TikTok Pixel после получения
   реальных ID (решить — переиспользовать GTM-WVNTW88N с живого сайта или создавать новый).
6. ⬜ Сверить адрес (пр. Достык, 32) и график работы в Google Maps и 2GIS.
7. ⬜ Передать черновики `privacy-policy/` и `consent/` на юридическую проверку.
8. ⬜ Выбрать дизайн-направление (А/Б, см. дизайн-брифинг) и докатить компоненты по
   остальным страницам, начиная с `/` и `/contacts/`.

Папка для сбора материалов от клиента (фото/видео/документы/лицензии) — `../saulemai-materials/`,
рядом с этим репозиторием.
